# Brief: tutorial

Teach one task end to end. Sections in order: What (one paragraph), Prerequisites (runtimes, accounts, background), numbered Steps (each a fenced command block with its language tag, then what success looks like), Validate-or-Not-executed (engine runs recorded, or honest labels), Unknowns (everything unverified).

Covers checks: description trigger-first; 400+ words; section headings present; fenced code with tags; a diagram, table, or image recommended; alt text on images; related ids resolved; short sentences in active voice; 300+ indexable words.
